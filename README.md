A mod to help take higher quality screenshots, mostly for the [wiki](hollowknight.wiki).

# Features and keybinds
- Number `1`: Toggle Hornet's model
- Number `2`: Toggle Hornet's light
- Number `3`: Toggle vignettes and status particles
- Number `4`: Toggle the HUD
- Number `0`: Toggle and synchronize 1, 2, 3 and 4
- Number `5`, 6, 7: Reset, increase and decrease zoom
- Number `8`: Noclip (arrow keys to control)
- Number `9`: Freecam (arrow keys to control)
- `Backspace`: Toggle enemies
- Numpad `+`, `-`: Increase and decrease brightness
- Numpad `*`, `/`: Increase and decrease the size of Hornet's light
- `=`: Reset brightness and Hornet's light
- `Shift` (while held): Make changes more precise

# Notes
- The keybinds are irrespective of keyboard layout, i.e. the `=` keybind is always the button directly to the left of backspace
- Zoom:
  - Default is `1`
  - Changes increase/decrease it additively by `0.05`, shift has no effect
- Brightness: 
  - Default is whatever is set as the in-game setting (usually `1`), it can be interpreted as a percentage
  - Regular changes increase/decrease it additively by `0.25`
  - Shift-changes increase/decrease it additively by `0.05`
- Hornet's light:
  - Default size is `3`
  - Regular changes increase/decrease it additively by `1`
  - Shift-changes increase/decrease it additively by `0.2`
- Noclip and Freecam:
  - Holding shift makes movement 1/10th the speed
